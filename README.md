# emoji-picker-tui

A terminal emoji picker. Browse by category or search by name and keywords in
Portuguese and English (names and keywords from [Unicode CLDR](https://cldr.unicode.org/)).
Built with [Bubble Tea](https://github.com/charmbracelet/bubbletea).

- Grid view; in kitty the emojis are drawn larger using the
  [text sizing protocol](https://sw.kovidgoyal.net/kitty/text-sizing-protocol/)
- `/` searches across all emojis, `tab` switches category
- Recently used emojis are remembered (`~/.local/state/emoji-picker/recent`)
- `enter` copies the emoji to the clipboard and quits

> The interface text is in Portuguese.

## Requirements

- `wl-copy` (Wayland) or `xclip` (X11)
- An emoji font (e.g. Noto Color Emoji)
- Go to build

## Install

```sh
git clone https://github.com/leonardoagodoy/emoji-picker-tui
cd emoji-picker-tui
go build -o emojis .
./emojis
```

## Keys

| Key | Action |
|---|---|
| arrows / `h` `j` `k` `l` | move |
| `enter` | copy emoji and quit |
| `tab` / `shift+tab` | next / previous category |
| `/` | search (`esc` closes) |
| `q` | quit |

## Updating the emoji data

`emojis.tsv` is embedded in the binary and generated by `gen.py` from the Unicode
`emoji-test.txt` and the CLDR annotations. Emojis your font cannot render are
dropped (needs `fontTools`):

```sh
python3 gen.py emoji-test.txt pt.xml en.xml [font.ttf] > emojis.tsv
```

Sources: https://unicode.org/Public/emoji/latest/emoji-test.txt and
`common/annotations/{pt,en}.xml` in https://github.com/unicode-org/cldr
